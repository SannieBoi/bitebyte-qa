# BUG-017: Sign up: username length error says "less than 15 characters" although 15 is allowed

| Field | Value |
| --- | --- |

| Related test case | SU-06 |
| Module | Sign up |
| Severity | Minor |
| Priority | Low |
| Environment | E1 – Windows 11, Opera GX, XAMPP |
| Status | Open |

## Preconditions

- On the Sign up page

## Steps to reproduce

1. Enter a 16-character username, fill the other fields with valid data
2. Click Sign up and read the error under Username

## Test data

Username: abcdefghijklmnop (16 characters)

## Expected result

The error states the real maximum, e.g. "Username must be at most 15 characters".

## Actual result

"Username must be less than 15 characters". A 15-character username is accepted (SU-05), so the message suggests a limit of 14.

## Reproducibility

Always

## Attachments

_None: the message text is quoted above._

## Notes

`checkLength()` in `signup.js` prints `must be less than ${max} characters` while the check is `length > max`.
